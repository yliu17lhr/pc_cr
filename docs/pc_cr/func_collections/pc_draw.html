Module pc_cr.func_collections.pc_draw

Created on Tue Apr 30 11:53:53 2024 @author: yiyanliu

This module provides functions for visualising crack detection and measurement results of PC-Cr, showing identified feature point clusters based on kinematic properties as well as visualising identified cracks and their measurements.
